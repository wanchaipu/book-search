# ค้นหาหนังสือ (Book Search)

เว็บค้นหาทะเบียนหนังสือ — static site ไฟล์เดียว ไม่ต้องมี backend/DB

ข้อมูลมาจาก Google Sheet **"25680502-ลงทะเบียนหนังสือ ชั้น 2-3 (ล่าสุด)"** แผ่นแรก (ชั้น 2)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|------|--------|
| `index.html` | หน้าค้นหา (ค้นหลายคำ, กรองตามหมายเหตุ/สำนักพิมพ์, ไฮไลต์คำ, แชร์ลิงก์ผลค้นได้ `?q=`) |
| `data/books.csv` | ข้อมูลดิบ export จากชีต |
| `data/books.json` | ข้อมูลที่หน้าเว็บโหลด (สร้างจาก CSV) |
| `scripts/build.py` | แปลง CSV → JSON |

## อัปเดตข้อมูลจากชีต

1. Google Sheet → เลือกแผ่นแรก → ไฟล์ → ดาวน์โหลด → CSV
2. บันทึกทับ `data/books.csv`
3. `python3 scripts/build.py`
4. commit + push

## ปุ่ม "ซิงก์จาก Google Sheet"

หน้าเว็บมีปุ่มซิงก์ — กดแล้วดึง CSV จากชีตมาแสดงทันที **โดยไม่ต้อง push** (ทำงานในเบราว์เซอร์คนที่กด
และจำไว้ในเครื่องนั้น กดซิงก์ใหม่เมื่อไหร่ก็ได้ข้อมูลล่าสุด)

**ต้องตั้งค่า 2 อย่างก่อนปุ่มถึงจะโผล่:**

1. ในชีต: ไฟล์ → แชร์ → **เผยแพร่ไปยังเว็บ** → เลือกแผ่น "ชั้น 2" → รูปแบบ **CSV** → เผยแพร่ แล้วคัดลอกลิงก์
   (หน้าตาแบบ `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=0&single=true&output=csv`)
2. ใน `index.html` ใส่ลิงก์นั้นที่ตัวแปรบรรทัดแรกของ `<script>`:
   ```js
   var SHEET_CSV_URL = 'วางลิงก์ CSV ตรงนี้';
   ```
   ปล่อยว่าง = ซ่อนปุ่ม ใช้ข้อมูลใน `data/books.json` อย่างเดียว

> ปุ่มนี้ไม่ได้แก้ไฟล์ใน repo — ถ้าอยากให้ข้อมูลในไฟล์ตรงกับชีตถาวร (คนเปิดใหม่เห็นเลยโดยไม่ต้องกดซิงก์)
> ยังต้องทำตามขั้นตอน "อัปเดตข้อมูลจากชีต" ด้านบน
>
> รูปจากชีตใช้คอลัมน์ `รูป` · ถ้าชีตไม่มีรูป ระบบจะคงรูปใน `images/` ของเล่มนั้นไว้ให้

## รูปปกหนังสือ

ยังไม่มีรูป → หน้าเว็บสร้างปกสำรองให้ (สีตามหมายเหตุ/สำนักพิมพ์ + ชื่อเรื่อง) ใส่รูปจริงได้ 2 วิธี:

1. **ใส่ในชีต** — เพิ่มคอลัมน์ชื่อ `รูป` ใส่ URL รูป หรือลิงก์ Google Drive (ต้องแชร์ "ทุกคนที่มีลิงก์")
2. **ใส่ไฟล์ใน repo** — วางไฟล์ `images/<เลขทะเบียน>.jpg` เช่น `images/001316.jpg` (รองรับ .jpg .jpeg .png .webp)

แล้วรัน `python3 scripts/build.py` ใหม่ (ถ้ามีทั้ง 2 แบบ ใช้คอลัมน์ในชีตก่อน) · รูปที่โหลดไม่ขึ้นจะกลับไปใช้ปกสำรองเอง · กดที่รูปเพื่อดูขนาดใหญ่

## รันบนเครื่อง

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

(เปิดด้วย `file://` ตรงๆ ไม่ได้ เพราะหน้าเว็บ fetch `data/books.json`)
